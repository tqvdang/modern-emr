# Patient Portal - Next.js

Modern patient-facing web application with PWA capabilities

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- React Query
- tRPC
- Zustand

## Getting Started

### Prerequisites
- Node.js 18+
- npm/yarn

### Installation
```bash
npm install
npm run dev
```

### Build
```bash
npm run build
npm start
```

## Features
- **PWA Support**: Installable on mobile devices, works offline
- **Patient-Centric**: Appointment booking, medical records access, messaging
- **Mobile-First**: Optimized for touch devices and mobile usage
- **Real-time Updates**: Live notifications and data synchronization
- **Multi-language Support**: i18n for diverse patient populations
- **Responsive Design**: Works on phones, tablets, and desktops
