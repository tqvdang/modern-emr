# AI Service - Python FastAPI

AI/ML service for medical image processing and computer vision tasks

## Tech Stack
- Python 3.11+
- FastAPI
- OpenCV
- TensorFlow/PyTorch
- Uvicorn

## Getting Started

### Prerequisites
- Python 3.11+
- pip or pipenv

### Installation
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

### API Documentation
Available at `/docs` when running.

## Features
- Medical image processing
- Computer vision analysis
- AI-powered diagnostics support
